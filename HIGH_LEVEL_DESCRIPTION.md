# Aetheria — high-level description

**A clocked organism on one private PC:** a mouth (local admin / architect) and a plant (detached ticks). Chat is not the runtime.

This repository publishes the **control plane**: supervisor, watchdog, identity-checked stop, measured entry path, continuity audit, and documentation.

Private deployment state — living memory, companion chat, host configuration, model adapters — remains on the operator machine.

## One sentence

Scale a serious AI *job* (continuity, host truth, gated self-mod) down onto a home PC: start a loop, persist progress, recover from crashes, treat process restarts as normal, and never let the chat window parent the clock.

## What it is / is not

| Is | Is not |
|----|--------|
| Detached plant clock + on-disk ledger | A ChatGPT clone |
| Chat never owns the schedule | AUTORUN after every crash |
| Fail-closed facts from disk | Invented GPU/RAM theater |
| Public control plane you can clone | A dump of private living / chat logs |
