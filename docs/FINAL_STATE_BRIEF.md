The evidence index lives at the repository root: [FINAL_STATE_BRIEF.md](../FINAL_STATE_BRIEF.md).

That page separates **Real**, **Proved**, **Pending**, and **Locked**, with receipts beside the claims. **Proved** there means a scrubbed gate file or a scrubbed dual receipt is in this repo.
