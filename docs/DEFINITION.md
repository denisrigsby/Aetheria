# Aetheria — definition

**Name:** Aetheria  
**Retire as definition:** "sovereign agent"

## Need

People need AI work that **keeps going when the chat dies** — overnight, after a crash, without babysitting a fragile window.

## One-liner

> **Aetheria** is the local plant clock that does that on your Windows PC. Chat is a mouth you can open or close. The work clock is not the chat.

## True expansion

- **Plant clock ≠ chat.** Continuity lives in the plant spine; Talk-face does not parent the clock.
- **Two faces, one plant.** Talk-face = scrubbed safety mouth; Forge = industrial console.
- **Fail-closed power.** Writes through typed apply / pending brief / watchdog — never silent disk from the mouth.
- **Origin.** Solo human–AI collaboration, built on Windows as a real operator machine.

## Forbidden soft frames

ChatGPT clone · multi-agent cloud framework theater · crypto/"sovereign" branding · soft-green claims without gates
