# WOW demo (public reference)

## What you should feel in 60 seconds

1. A **plant pulse** starts ticking.
2. **Talk-face** opens (the mouth).
3. You **close the mouth**.
4. The **pulse keeps rising**.

That is the product need: AI work that keeps going when chat dies.

## Run

```powershell
python -u scripts/demo_wow.py
# or double-click Demo-Wow.bat on Windows
```
