# Discovery vocabulary (honest)

Searchable words are allowed when a named receipt or a named test in this repo binds them. [CLAIMS_TAXONOMY.md](CLAIMS_TAXONOMY.md).

## Hook words (only with the bind below)

local AI agent · Windows · long-running · persistent · background · watchdog · local-first · agent-runtime · plant clock

## Bind each hook

| Phrase | Bind to |
|--------|---------|
| local AI agent / Windows | Operator plant on Windows, plus this public control-plane export. This tree is **PRIVATE_AHEAD** |
| long-running / overnight | `gate_endurance_v1`: 30 minutes, mouth closed, tick advanced. Longer than that window is **Locked** |
| survives when chat closes | Mock: `scripts/demo_continuity.py`. Plant: the same 30-minute receipt. Not a standing PASS beyond that window |
| watchdog | Process supervision docs. Unrelated-process survival and clean stop ≠ crash stay **Pending** |
| persistent | On-disk control-plane files in this repo |
| restart-safe | **Pending**. Clean stop ≠ crash is **PARTIAL** on [RELEASE_GATE_ASSURANCE.md](RELEASE_GATE_ASSURANCE.md) |

## Do not lead with

autonomous · self-healing · production-ready · enterprise-grade · revolutionary · chatbot · ChatGPT clone · CrewAI/LangGraph multi-agent · AGI · sovereign · crypto · "never fails"

Those words are **Locked** unless a later gate proves one of them and names the scope beside the claim. This page does not prove them.

P1–P5 stay internal certification. They are not a discovery claim.
